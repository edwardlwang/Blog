## 前言

排序是计算机科学中最基础也最经典的问题之一。无论是数据库查询、搜索引擎排名，还是编译器的符号表管理，都离不开排序。据估计，历史上计算机运行的所有周期中，有相当可观的比例消耗在排序上。

排序算法的种类繁多，从最简单的冒泡排序到精妙的快速排序，从基于比较的归并排序到突破比较下界的基数排序，每一种都有其独特的思路与适用场景。

本文系统梳理常见排序算法的原理、实现、复杂度与适用场景，代码示例统一使用 C++17。

---

## 一、排序算法分类

按是否依赖元素之间的比较，排序算法可分为两大类：

**基于比较的排序**：

- 通过比较元素大小决定顺序
- 时间复杂度下界为 Ω(n log n)
- 代表：冒泡、插入、选择、希尔、归并、快速、堆排序

**非比较排序**：

- 不比较元素，利用元素的特殊性质（如整数范围、位数）
- 可突破 Ω(n log n) 下界
- 代表：计数排序、桶排序、基数排序

按稳定性可分为：

- **稳定排序**：相等元素的相对顺序在排序后保持不变
- **不稳定排序**：相等元素的相对顺序可能改变

稳定性在多关键字排序中至关重要。例如先按姓名排序，再按年龄排序，若第二次排序是稳定的，则同龄人之间会保持姓名有序。

## 三、基于比较的排序

### 3.1 冒泡排序

**思路**：重复遍历数组，比较相邻元素，若顺序错误则交换。每一轮将最大值"冒泡"到末尾。

```cpp
void bubbleSort(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; ++j) {
            if (nums[j] > nums[j + 1]) {
                swap(nums[j], nums[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;   // 已有序，提前退出
    }
}
```

**分析**：

- 最好情况（已有序）只需一趟扫描，O(n)。
- 冒泡排序是稳定的——交换仅在严格大于时发生。
- 实际工程中几乎不用，仅作教学示例。

---

### 3.2 插入排序

**思路**：将数组分为"已排序"和"未排序"两部分，每次将未排序部分的第一个元素插入到已排序部分的正确位置。

```cpp
void insertionSort(vector<int>& nums) {
    int n = nums.size();
    for (int i = 1; i < n; ++i) {
        int key = nums[i];
        int j = i - 1;
        while (j >= 0 && nums[j] > key) {
            nums[j + 1] = nums[j];
            --j;
        }
        nums[j + 1] = key;
    }
}
```

**分析**：

- 对近乎有序的数据效率极高，最好情况 O(n)。
- 稳定排序，相等元素不会被交换。
- **实际应用**：作为快速排序和归并排序的"小区间优化"——当子数组长度小于 16 左右时改用插入排序，减少递归开销。

---

### 3.3 选择排序

**思路**：每一轮从未排序部分选出最小值，放到已排序部分的末尾。

```cpp
void selectionSort(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n - 1; ++i) {
        int minIdx = i;
        for (int j = i + 1; j < n; ++j) {
            if (nums[j] < nums[minIdx]) minIdx = j;
        }
        swap(nums[i], nums[minIdx]);
    }
}
```

**分析**：

- 无论数据如何，比较次数固定为 n(n-1)/2，没有最好情况。
- 交换次数最多 n-1 次，是所有排序中最少的。
- **不稳定**：交换可能改变相等元素的相对顺序。
- 适合元素交换代价极高的场景。

---

### 3.4 希尔排序

**思路**：插入排序的改进版。先按较大的步长进行分组插入排序，逐步缩小步长，最终步长为 1 时进行标准插入排序。

```cpp
void shellSort(vector<int>& nums) {
    int n = nums.size();
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int key = nums[i];
            int j = i - gap;
            while (j >= 0 && nums[j] > key) {
                nums[j + gap] = nums[j];
                j -= gap;
            }
            nums[j + gap] = key;
        }
    }
}
```

**分析**：

- 复杂度取决于步长序列。使用 Hibbard 序列可达 O(n^1.5)，使用 Sedgewick 序列可达 O(n^1.3)。
- 不稳定排序。
- 优点是无递归、空间 O(1)，适合嵌入式场景。

---

### 3.5 归并排序

**思路**：分治法。将数组递归地一分为二，分别排序，再合并两个有序子数组。

```cpp
void merge(vector<int>& nums, int lo, int mid, int hi, vector<int>& tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        tmp[k++] = (nums[i] <= nums[j]) ? nums[i++] : nums[j++];
    }
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi)  tmp[k++] = nums[j++];
    for (int t = lo; t <= hi; ++t) nums[t] = tmp[t];
}

void mergeSortHelper(vector<int>& nums, int lo, int hi, vector<int>& tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSortHelper(nums, lo, mid, tmp);
    mergeSortHelper(nums, mid + 1, hi, tmp);
    merge(nums, lo, mid, hi, tmp);
}

void mergeSort(vector<int>& nums) {
    vector<int> tmp(nums.size());
    mergeSortHelper(nums, 0, nums.size() - 1, tmp);
}
```

**分析**：

- 时间复杂度稳定在 O(n log n)，不受数据分布影响。
- **稳定排序**：合并时 `nums[i] <= nums[j]` 选择左半部分，保证稳定性。
- 空间 O(n)，是主要的缺点。
- **实际应用**：
  - Java 的 `Arrays.sort(Object[])`（TimSort 的基础）
  - C++ 的 `std::stable_sort`
  - 外排序（数据无法全部载入内存时）
  - 链表的排序（链表归并只需 O(1) 额外空间）

### 3.6 快速排序

**思路**：分治法。选择一个基准元素（pivot），将数组分为"小于基准"和"大于基准"两部分，递归处理两侧。

```cpp
int partition(vector<int>& nums, int lo, int hi) {
    // 三数取中，避免有序数据退化
    int mid = lo + (hi - lo) / 2;
    if (nums[mid] < nums[lo]) swap(nums[mid], nums[lo]);
    if (nums[hi] < nums[lo])  swap(nums[hi], nums[lo]);
    if (nums[hi] < nums[mid]) swap(nums[hi], nums[mid]);
    swap(nums[mid], nums[hi - 1]);      // 将中位数放到 hi-1 位置
    int pivot = nums[hi - 1];

    int i = lo, j = hi - 1;
    while (true) {
        while (nums[++i] < pivot) {}
        while (nums[--j] > pivot) {}
        if (i >= j) break;
        swap(nums[i], nums[j]);
    }
    swap(nums[i], nums[hi - 1]);
    return i;
}

void quickSortHelper(vector<int>& nums, int lo, int hi) {
    if (lo >= hi) return;
    if (hi - lo < 16) {                 // 小区间用插入排序
        insertionSortRange(nums, lo, hi);
        return;
    }
    int p = partition(nums, lo, hi);
    quickSortHelper(nums, lo, p - 1);
    quickSortHelper(nums, p + 1, hi);
}

void quickSort(vector<int>& nums) {
    quickSortHelper(nums, 0, nums.size() - 1);
}
```

**分析**：

- 平均 O(n log n)，最坏 O(n²)（如已排序且取首元素为基准）。
- 不稳定排序。
- **优化技巧**：
  1. **三数取中**：避免对有序数据退化。
  2. **小区间插入排序**：减少递归深度和函数调用开销。
  3. **三路划分**（荷兰国旗问题）：处理大量重复元素时性能更优。
  4. **尾递归优化**：先递归较短的一侧，减少栈深度。

**三路划分版本**（推荐处理含大量重复元素的场景）：

```cpp
void quickSort3Way(vector<int>& nums, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = nums[lo];
    int lt = lo, gt = hi, i = lo + 1;
    while (i <= gt) {
        if (nums[i] < pivot) swap(nums[lt++], nums[i++]);
        else if (nums[i] > pivot) swap(nums[i], nums[gt--]);
        else ++i;
    }
    quickSort3Way(nums, lo, lt - 1);
    quickSort3Way(nums, gt + 1, hi);
}
```

**实际应用**：

- C 的 `qsort`
- C++ 的 `std::sort`（Introsort = 快排 + 堆排 + 插入排序的混合）
- Java 的基本类型排序（`Arrays.sort(int[])`）

### 3.7 堆排序

**思路**：利用大顶堆的性质。先将数组构建为大顶堆，然后反复取出堆顶元素放到数组末尾。

```cpp
void siftDown(vector<int>& nums, int n, int i) {
    while (true) {
        int largest = i;
        int l = 2 * i + 1, r = 2 * i + 2;
        if (l < n && nums[l] > nums[largest]) largest = l;
        if (r < n && nums[r] > nums[largest]) largest = r;
        if (largest == i) break;
        swap(nums[i], nums[largest]);
        i = largest;
    }
}

void heapSort(vector<int>& nums) {
    int n = nums.size();
    // 建堆：从最后一个非叶子节点开始
    for (int i = n / 2 - 1; i >= 0; --i) siftDown(nums, n, i);
    // 逐个取出堆顶
    for (int i = n - 1; i > 0; --i) {
        swap(nums[0], nums[i]);
        siftDown(nums, i, 0);
    }
}
```

**分析**：

- 时间稳定 O(n log n)，空间 O(1)。
- 不稳定排序。
- 常数比快排大，但最坏情况有保证。
- **实际应用**：
  - 优先队列（`std::priority_queue`）
  - 求 Top K（用大小为 k 的堆）
  - 实时系统中的排序（避免快排的最坏情况）

## 四、非比较排序

### 4.1 计数排序

**思路**：统计每个值出现的次数，然后按值域顺序输出。适合值域较小的整数排序。

```cpp
void countingSort(vector<int>& nums) {
    if (nums.empty()) return;
    int maxVal = *max_element(nums.begin(), nums.end());
    int minVal = *min_element(nums.begin(), nums.end());
    int range = maxVal - minVal + 1;

    vector<int> count(range, 0);
    for (int x : nums) ++count[x - minVal];

    // 前缀和，确定每个元素的最终位置
    for (int i = 1; i < range; ++i) count[i] += count[i - 1];

    vector<int> output(nums.size());
    for (int i = nums.size() - 1; i >= 0; --i) {
        output[--count[nums[i] - minVal]] = nums[i];
    }
    nums = output;
}
```

**分析**：

- 时间复杂度 O(n + k)，k 为值域大小。
- 空间 O(n + k)。
- **稳定排序**：逆序遍历输入，保证相等元素的相对顺序。
- 当 k 远大于 n 时（如排序 1e5 个值域为 1e9 的数），空间浪费严重，不适合。

---

### 4.2 桶排序

**思路**：将元素按值域分配到若干桶中，每个桶内单独排序，最后按顺序合并。

```cpp
void bucketSort(vector<double>& nums) {
    int n = nums.size();
    if (n <= 1) return;

    vector<vector<double>> buckets(n);
    for (double x : nums) {
        int idx = min((int)(x * n), n - 1);
        buckets[idx].push_back(x);
    }

    for (auto& bucket : buckets) {
        sort(bucket.begin(), bucket.end());   // 桶内可用插入排序
    }

    int idx = 0;
    for (const auto& bucket : buckets) {
        for (double x : bucket) nums[idx++] = x;
    }
}
```

**分析**：

- 平均 O(n + k)，最坏 O(n²)（所有元素落入同一桶）。
- 适合均匀分布的浮点数。
- 桶的数量和大小对性能影响大，实践中需根据数据分布调整。

---

### 4.3 基数排序

**思路**：按位排序，从低位到高位（LSD）或从高位到低位（MSD）。每一位的排序使用稳定的计数排序。

```cpp
void countingSortByDigit(vector<int>& nums, int exp) {
    int n = nums.size();
    vector<int> output(n);
    vector<int> count(10, 0);

    for (int x : nums) ++count[(x / exp) % 10];
    for (int i = 1; i < 10; ++i) count[i] += count[i - 1];

    for (int i = n - 1; i >= 0; --i) {
        int digit = (nums[i] / exp) % 10;
        output[--count[digit]] = nums[i];
    }
    nums = output;
}

void radixSort(vector<int>& nums) {
    if (nums.empty()) return;
    int maxVal = *max_element(nums.begin(), nums.end());
    for (int exp = 1; maxVal / exp > 0; exp *= 10) {
        countingSortByDigit(nums, exp);
    }
}
```

**分析**：

- 时间复杂度 O(d(n + k))，d 为最大位数，k 为基数。
- **稳定排序**（每一位的计数排序都稳定）。
- 适合位数较少的整数或定长字符串。
- **实际应用**：后缀数组构造、GPU 并行排序。

## 五、C++ STL 中的排序

标准库提供了多个排序函数，各有适用场景：

| 函数                | 算法                            | 稳定性 | 复杂度     |
| ------------------- | ------------------------------- | ------ | ---------- |
| `std::sort`         | Introsort（快排 + 堆排 + 插入） | 不稳定 | O(n log n) |
| `std::stable_sort`  | 归并排序（TimSort 变体）        | 稳定   | O(n log n) |
| `std::partial_sort` | 堆排序变体                      | 不稳定 | O(n log k) |
| `std::nth_element`  | 快速选择                        | 不稳定 | 平均 O(n)  |
| `std::sort_heap`    | 堆排序                          | 不稳定 | O(n log n) |

**用法示例**：

```cpp
vector<int> nums = {3, 1, 4, 1, 5, 9, 2, 6};

// 升序
sort(nums.begin(), nums.end());

// 降序
sort(nums.begin(), nums.end(), greater<int>());

// 稳定排序（多关键字场景）
stable_sort(nums.begin(), nums.end());

// 求第 k 小的元素（部分排序，比全排序快）
nth_element(nums.begin(), nums.begin() + 3, nums.end());
int kthSmallest = nums[3];
```

**为什么 `std::sort` 是 Introsort？**

纯快排最坏 O(n²)。Introsort 在递归深度超过 2 log n 时切换为堆排序，保证最坏 O(n log n)；当子数组长度小于阈值时切换为插入排序，减少递归开销。这是工程上"保证最坏性能 + 优化平均性能"的经典组合。

## 六、排序算法的选择指南

不同场景下的推荐算法：

| 场景             | 推荐算法                      | 理由               |
| ---------------- | ----------------------------- | ------------------ |
| 通用场景         | 快速排序 / `std::sort`        | 平均性能最优       |
| 需要稳定排序     | 归并排序 / `std::stable_sort` | 保持相等元素顺序   |
| 数据近乎有序     | 插入排序                      | 接近 O(n)          |
| 内存受限         | 堆排序 / 希尔排序             | 空间 O(1)          |
| 链表排序         | 归并排序                      | 无需随机访问       |
| 小数组（n < 16） | 插入排序                      | 常数小             |
| 值域小的整数     | 计数排序                      | O(n + k)           |
| 均匀分布的浮点   | 桶排序                        | O(n)               |
| 定长整数/字符串  | 基数排序                      | O(d(n + k))        |
| 只需前 k 小      | 堆排序 / 快速选择             | O(n log k) 或 O(n) |

## 七、常见陷阱

1. **快速排序的基准选择**  
   若始终选首元素为基准，对有序数组会退化为 O(n²)。应使用三数取中或随机化基准。

2. **归并排序的稳定性**  
   合并时若 `nums[i] <= nums[j]` 选择左侧，则稳定；若用 `<` 则不稳定。这一点容易写错。

3. **计数排序的值域**  
   值域过大时（如 1e9），计数数组会占用巨额内存。此时应改用基数排序或哈希表统计。

4. **基数排序的负数处理**  
   标准基数排序只处理非负数。若含负数，需将其映射到非负范围或分别处理。

5. **堆排序的下标计算**  
   0-based 数组中，节点 i 的左孩子是 `2i+1`，右孩子是 `2i+2`，最后一个非叶子节点是 `n/2 - 1`。用 1-based 公式会数组越界。

6. **`std::sort` 的比较器必须严格弱序**  
   若比较器写成 `a <= b`，可能触发未定义行为（如 std::sort 崩溃）。应使用 `a < b` 作为严格弱序。

7. **稳定性与比较器的交互**  
   `std::sort` 不稳定，若需要稳定，必须用 `std::stable_sort` 或把比较键扩展为多字段。

## 九、总结

排序算法的学习，本质上是在**时间、空间、稳定性、实现难度**这四个维度之间做权衡。

- **冒泡、插入、选择**：简单直观，适合小规模或教学。
- **希尔**：插入排序的改进，无递归，空间 O(1)。
- **归并**：稳定、可预测，适合链表和外排序。
- **快速**：平均最快，工程中配合优化成为事实标准。
- **堆排**：最坏情况有保证，空间 O(1)。
- **非比较排序**：在特定条件下突破 O(n log n) 下界。

工程实践中的排序通常是**混合策略**：C++ 用 Introsort，Java 用 TimSort，Python 用 Timsort。理解每种算法的边界与组合方式，比记住代码更重要。

一句话概括：

> **没有最快的排序算法，只有在特定场景下最合适的排序算法。**
